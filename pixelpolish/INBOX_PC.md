## Письмо #23 — 2026-09-04 — ПЕРЕЕЗД НА ПК: проверка источников уходит на ПК

Решение Седрака: переносим работу на ПК полностью. Единственное возражение, которое
у меня было, снято измерением — ниже что именно проверено.

### Что было измерено

| проверка | результат |
|---|---|
| `curl` на `loc.gov/item/<id>/?fo=json` **с ПК** | HTTP 403, `Cf-Mitigated: challenge`, `cType: 'interactive'` |
| то же с браузерным User-Agent (Chrome/124 Windows) | тот же 403 — заголовок не помогает |
| то же **из облака** (04.09) | HTTP 200, 49 658 байт JSON |
| **тот же адрес в обычном Chrome на ПК** | **открылся, текст виден** |

Вывод: **loc.gov с ПК не заблокирован.** Перед ним стоит Cloudflare, который требует
выполнить JavaScript и принять куки. `curl` и `requests` этого не умеют — они только
качают текст. Настоящий браузер проверку проходит. То есть не хватало не доступа, а
инструмента.

Раньше в переписке я говорил, что источники с ПК недоступны. Это было неверно:
я мерил `curl`, а не браузер. Снимаю.

### Что делать на ПК

**1. Отдельный профиль браузера для проверки источников.** По правилу из
`pixelpolish/MCP_BROWSER.md` — свой профиль на агента, в основной профиль Седрака
не лезть:

    Проверка источников   C:\pixelpolish\loc-profile

Ставить по инструкции из `MCP_BROWSER.md`. Для этой задачи (открыть страницу и
забрать текст) годится любой из двух серверов; `playwright-mcp` — умолчание.

**2. Приёмочный тест — без него не считать сделанным.** Через браузерный MCP забрать
JSON по адресу:

    https://www.loc.gov/item/2018666799/?fo=json

Годится только если вернулся JSON, а не страница «Just a moment». Показать в отчёте:
код ответа, размер тела, и поле `created_published` из `item`. Облако видит по этому
адресу 49 658 байт — порядок должен совпасть.

**3. Если Cloudflare покажет проверку («Just a moment», галочка, картинки) — СТОП
и отчёт.** Капчу не обходить, скриптов обхода не писать. Правило Седрака, не
обсуждается. Пропуск Cloudflare живёт в куке профиля и со временем протухает —
тогда Седрак один раз открывает страницу руками, и профиль снова работает.
