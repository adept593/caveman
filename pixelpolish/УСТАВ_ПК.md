# Устав агента на ПК (PixelPolish)

Читать при запуске каждой новой сессии на компьютере Седрака. Это правила
владельца, а не пожелания. Ниже — то, что нельзя нарушать, и то, что нужно
знать, чтобы не переспрашивать.

## Запреты. Без исключений

1. **Пароли вводит только Седрак.** Агент не логинится нигде и не просит
   разрешения залогиниться. Профиль браузера один раз открывает человек, дальше
   агент работает уже залогиненным.
2. **Капча — стоп и отчёт.** Ни обходить, ни писать скрипты обхода, ни
   подбирать User-Agent, чтобы проскочить. Увидел проверку — доложил.
3. **На YouTube ничего не заливается без отдельного слова Седрака, каждый раз
   заново.** Прошлое разрешение не переносится на следующий ролик. В коде это
   флаг `--confirm` у `publish/yt_publish.py`; ставит его человек.
4. **Опубликованные ролики не скрывать и не удалять.**
5. **Папку `legal/` и файлы `URIST*` не трогать и не коммитить.** В них правовые
   материалы Седрака.
6. **Репозиторий `adept593/caveman` — публичный.** Туда только текст. Ни
   картинок, ни видео, ни рабочих материалов, ни ключей. Проверено `.gitignore`,
   но полагаться на него мало: смотри, что коммитишь.
7. **Реальные деньги и ключи бирж — только по отдельному слову Седрака.**
   Трейдер работает на бумаге.
8. **Платные API не подключать.**
9. **На рабочий стол файлы не копировать.**
10. **Веса моделей — только с huggingface.co и github.com.** Зеркала не
    использовать. `torch` не трогать.

## Где что лежит

| | путь |
|---|---|
| Репозиторий | `D:\PixelPolish\repo\`, ветка `claude/pixelpolish-restore-eq9sjs` |
| Ключи и токены | `D:\secrets\` |
| Фото, видео, музыка, загрузки | диск **D** |
| Модели | диск **C** |
| Реставрация | `C:\pixelpolish\restore_v5\` (своё venv, свои веса) |
| Профили браузера | `C:\pixelpolish\<агент>-profile`, у каждого свой |

Диск D — для тяжёлого. Диск C — для моделей. В основной профиль Chrome Седрака
не лезть: там почта и банк, и сам Chrome удалённую отладку на нём не включает.

## Окно генерации

**Тяжёлые прогоны только с 22:00 до 09:00 по Кемерово** (UTC+7 круглый год),
то есть с 15:00 до 02:00 UTC. Вне окна запрещены: Kontext, ComfyUI, апскейл,
рендер видео с перекодированием, пакетные прогоны. Разрешено круглосуточно:
отчёты, git, метрики по готовым картинкам, разведка, реестры, заливка — она
нагружает сеть, а не видеокарту. Идущий прогон не обрывать, следующий вне окна
не начинать. Подробности — `ОКНО_ГЕНЕРАЦИИ.md`.

## Проверка источников

Библиотека Конгресса (`loc.gov`) — источник дат, фамилий фотографов и признака
ручной подкраски. С ПК она **доступна, но только через браузер**: перед ней
стоит Cloudflare, который требует выполнить JavaScript и принять куки. `curl` и
`requests` получают 403 с `Cf-Mitigated: challenge`. Подмена User-Agent не
помогает — заголовок соврать можно, JavaScript выполнить нельзя.

Поэтому запросы к `loc.gov` идут через браузерный MCP с профилем
`C:\pixelpolish\loc-profile`. Ставится по `MCP_BROWSER.md`.

Приёмочный тест: `https://www.loc.gov/item/2018666799/?fo=json` должен вернуть
JSON около 49 700 байт. Вернулась страница «Just a moment» — тест не пройден,
это капча, см. запрет №2.

**Поле `date` в ответе LOC — машинный ключ сортировки, а не датировка.**
Настоящая дата лежит в `created_published`. На этом уже один раз обожглись.

## Правило №0 — дедуп

Ни одна пластина не используется дважды. Перед рендером и перед заливкой
сверяться с реестром. Реестр читают **глазами**, скрипт его не читает — значит
проверка держится на дисциплине, а не на коде.

Сверка реестра с реальностью: `python3 pixelpolish/state/reconcile_ledger.py`
— он берёт список роликов прямо с каналов через API и показывает расхождения.
Только чтение, на YouTube ничего не пишет.

## Планка качества

Совет критиков ≥7 обязателен. Брак не заливать — лучше меньше. При заливке
отмечать «Altered or synthetic content»: лица на выцветших пластинах
синтезированы, и это надо признавать.

Текст роликов Photo Rescue и Restored History — **только по-английски**,
правописание американское (`color`, не `colour`). Шаблон — `VIDEO_TEXT.md`.

## Отчёт

Одно сообщение по итогам, со ссылками и цифрами. Вопросы Седраку — только если
нужен его клик или его выбор. Цифры не выдумывать: любое число в отчёте должно
быть из реального прогона, а не из памяти.
