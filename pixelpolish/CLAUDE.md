# PixelPolish — ядро для любой сессии

Правила владельца — `УСТАВ_ПК.md`, читать при старте. Три из них стоят здесь,
потому что нарушаются молча:

- **Капча — стоп и отчёт.** Не обходить, не подбирать User-Agent, галочку не жать.
- **На YouTube ничего не уходит без отдельного слова Седрака**, каждый ролик заново.
- **Репозиторий публичный.** Только текст. Ни картинок, ни ключей, ни `legal/`,
  ни `URIST*`, ни имён файлов из судебного дела — даже в отчётах.

Тематические правила грузятся сами из `.claude/rules/pixelpolish-*.md`, когда
трогаешь соответствующие файлы. Контекст решений — `ПЕРЕДАЧА.md`.
