# Проверка источников (loc.gov)

Библиотека Конгресса — источник дат, фамилий фотографов и признака ручной
подкраски. С ПК она доступна **только через браузер**: перед ней Cloudflare,
`curl`/`requests` получают 403 `Cf-Mitigated: challenge`. Подмена User-Agent не
помогает и запрещена уставом.

Запросы идут через браузерный MCP с профилем `C:\pixelpolish\loc-profile`
(ставится по `MCP_BROWSER.md`). Turnstile проходит Седрак, руками, один раз;
пропуск живёт в куке профиля и протухает — тогда снова стоп и отчёт.

Приёмочный тест: `https://www.loc.gov/item/2018666799/?fo=json` → JSON около
49 700 байт. Страница «Just a moment» — тест не пройден. 503 «We're swamped» —
это их сторона, повторять раз в час.

**Поле `date` в ответе LOC — машинный ключ сортировки, а не датировка.**
Настоящая дата в `created_published`. В тексте роликов даты только с оговоркой
(`c. 1852`). На этом уже один раз обожглись.
