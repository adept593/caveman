# Генерация

**Тяжёлые прогоны только с 22:00 до 09:00 по Кемерово** (UTC+7 круглый год),
то есть 15:00–02:00 UTC. Вне окна не запускать: Kontext, ComfyUI, апскейл,
рендер видео с перекодированием, пакетные прогоны. Идущий прогон не обрывать,
следующий вне окна не начинать. Сомневаешься, грузит ли задача видеокарту —
считай, что грузит. Подробности — `ОКНО_ГЕНЕРАЦИИ.md`.

Круглосуточно можно: отчёты, git, метрики по готовым картинкам, разведка,
реестры, заливка (сеть, не видеокарта).

Промпты реставрации — `PROMPTS_RESTORE.md`, брать дословно, это промпты
владельца для image-модели. Настройки Kontext и две мины (`FluxKontextImageScale`
ужимает до 1 Мп; выше 1760 по длинной стороне — тихое вырождение) — `РЕЦЕПТ.md` §3.
Веса моделей — только с huggingface.co и github.com. `torch` не трогать.
