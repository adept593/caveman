# Правило №0 — дедуп

Ни одна пластина не используется дважды. Перед рендером и перед заливкой
сверяться с реестром `pixelpolish/state/used_photos_ledger.json` — глазами,
а затем скриптом:

    python pixelpolish/state/reconcile_ledger.py

Он берёт список роликов с каналов через API и показывает расхождения. Только
чтение, на YouTube ничего не пишет. Если ни один токен не открыл канал, скрипт
говорит «СВЕРКА НЕ ВЫПОЛНЕНА» — такой прогон не засчитывать.

Схема реестра: `used` — опубликовано, повтор запрещён; `used_episode` — пластины,
занятые эпизодом Restored History; `prepared` — занято под будущий ролик.
Один и тот же номер LOC пишут по-разному (`2017645715` и `(dag)2017645715`) —
скрипт нормализует, глаза должны тоже.

После каждой заливки — запись в реестр до заливки следующей.
