# Заливка и ключи

**Ни один ролик не уходит на YouTube без отдельного слова Седрака, каждый раз
заново.** В коде это флаг `--confirm` у `publish/yt_publish.py`; ставит его
человек. Агент готовит `meta.json`, показывает `--plan` и ждёт.

Опубликованные ролики не скрывать и не удалять. Прежние файлы не перезаписывать.

Ключи лежат в `$YT_SECRETS` (на ПК Седрака — `D:\secrets`): `api_key`,
`oauth_client.json` (два поля, без обёртки `installed`), `token_<канал>.json`.
Новые токены — только `publish/oauth_flow.py` (device flow): скрипт печатает код,
вход делает Седрак. Логиниться и просить разрешения на логин агенту нельзя.
Refresh упал с 401 — первым делом сверить `client_secret` с консолью Google.

При заливке отмечать «Altered or synthetic content»: лица на выцветших пластинах
синтезированы, и это надо признавать. `containsSyntheticMedia` API на чтение не
отдаёт — проверять в Студии.

Квота YouTube Data API сбрасывается в 07:00 UTC. Разведка (`vidiq.py`) идёт по
`api_key`, а не по токенам каналов.
